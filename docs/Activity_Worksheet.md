# Phiếu Hoạt Động Trên Lớp

## Tên hoạt động

**Sprint Phân Loại False Positive**

## Mục tiêu

Phân loại các finding thành `lỗi thật`, `false positive`, hoặc `cần thêm thông tin`, sau đó viết một dòng giải thích ngắn gọn cho mỗi finding.

## Thiết lập

- Thời gian: `20-25 phút`
- Tài liệu: finding cards in sẵn hoặc file Markdown
- Công cụ được phép dùng: snippet code, alert summary, prompt AI nếu giảng viên cho phép

## Hướng dẫn cho nhóm tham gia

1. Đọc từng finding card.
2. Chọn một nhãn: `lỗi thật`, `false positive`, hoặc `cần thêm thông tin`.
3. Ghi một dòng giải thích.
4. Chọn một finding để thảo luận kỹ hơn.
